# store-shots

`rn-kickstart-store` is a standalone Node 22 CLI with zero npm dependencies. It captures raw
screenshots from a booted simulator or emulator, renders them inside geometric device frames
with localized headline copy, and writes the result straight into the fastlane tree so
`deliver` / `supply` upload it with no mapping. Your job is to run the commands in order and
fix the config; do not draw frames or resize images by hand.

## Where to run it

Always from the **root of the generated project** (the folder that has `package.json` and
`store/`). The config lives at `store/kickstart.store.json`; rn-kickstart writes it when the
project was generated with `--store=yes`. If `store/` is missing, run `rn-kickstart-store init`.

If the command is not on PATH, run `node <react-native-kickstart checkout>/bin/store.mjs …`.

## Commands

| Command | What it does | Needs |
|---|---|---|
| `rn-kickstart-store init` | Writes `store/kickstart.store.json`, a placeholder `store/icon.png`, and the `fastlane/` metadata skeleton. | nothing |
| `rn-kickstart-store capture` | Sets a clean status bar (9:41, full battery/signal), screenshots the booted iOS simulator (`simctl`) or Android emulator (`adb`) into `store/shots/<locale>/NN-<id>.png`, one per `screens[]` entry. Walks `.maestro/store.yaml` if present. | a **booted** simulator/emulator with the app running |
| `rn-kickstart-store render` | Draws each capture inside a device frame on the configured background with the localized copy, at every size in `sizes`. Output: `fastlane/screenshots/<locale>/` (App Store) and `fastlane/metadata/android/<locale>/images/` (Play). | **Chrome or Edge installed** (headless, driven over CDP) |
| `rn-kickstart-store icons` | From the 1024×1024 `store/icon.png`: iOS asset catalog, Android adaptive layers + mipmaps, Play 512. | Chrome or Edge installed |
| `rn-kickstart-store check` | Validates the config, every `source` capture exists, sizes and formats are store-legal, copy exists for each locale. Exit 1 on problems. | nothing |

Each command accepts `--help`. `--config=<path>` points at a different config file.

## Config (`store/kickstart.store.json`)

- `locales`: e.g. `["en-US"]`. Every screen's `copy` needs one entry per locale.
- `device`, `sizes`: frame geometry and the store sizes to emit (`iphone-6-9`, `iphone-6-3`,
  `ipad-13`, `android-phone`, `android-tablet`).
- `format`: `jpeg` or `png` (alpha is stripped; stores reject transparency).
- `background`: `{ kind: "gradient" | "solid", from, to, angle }`.
- `icon`: path to the 1024×1024 master.
- `screens[]`: `{ id, source, copy: { "<locale>": { headline, subhead } } }`. Headlines support
  `*emphasis*` markup.

## Rules

- Run `check` before `render`; it tells you exactly which capture or copy is missing.
- `capture` fails with no booted device: tell the user to boot a simulator (`xcrun simctl boot`)
  or emulator and launch the app (`<pm> run ios` / `<pm> run android`) first.
- `render` or `icons` fails with "no Chrome/Edge": the user must install one of them; there is
  no bundled browser and no npm fallback.
- Keep the project's `fastlane/` tree as the only output location. Do not copy images elsewhere.
- To change the look, edit `kickstart.store.json` (background, template, rhythm, copy) and
  re-run `render`; never edit the rendered JPEG/PNGs.
- Replace the placeholder `store/icon.png` with the real master before `icons`.
